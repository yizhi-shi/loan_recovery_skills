## 为什么做这个

「借钱的时候是朋友，要钱的时候是仇人。」现实中出借人常卡在四个地方：

- **不会写借条**——只写"今借到某某 10 万元"，没写交付方式、利率、还款期限、管辖法院，起诉时说不清"钱到底给没给"。
- **不懂时效**——钱拖了四五年才想起来告，对方一句"诉讼时效已过"就可能输；或者催收方式不对，产生不了时效中断的效力。
- **不知道去哪告、带什么**——跑错法院、材料不全、被告信息不明确的，立案窗口来回跑；不知道可以争取在**自己所在地**起诉。
- **上了法庭不会说**——法庭调查、举证质证、法庭辩论分不清，面对对方"这是赠与""早还了""借条是逼我写的"等抗辩不知道怎么接。

这个 skill 把《民法典》借款合同章、《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》（法释〔2020〕17 号）、民事诉讼法程序规则、证据规则与诉讼费用标准整理成**可被 AI 助手按需加载**的结构化参考，并配套 7 类可直接填用的法律文书模板、一个利息计算器和一套庭审辩论提纲，让普通人在**决定要不要告的第一天**就能拿到接近执业律师初诊水平的分析。

## 能解决什么问题

### ✅ 事前：借条怎么写才有效

- 借条 / 欠条 / 收据的区别与适用场景
- 一份「法院最喜欢」的规范借条模板：金额大小写、交付方式与流水号、利率上限、逾期利率、实现债权费用、管辖条款、送达地址、保证人、夫妻共债确认
- 常见致命错误清单（只有小写金额、签名与身份证名不一致、"月息 2 分"超上限、现金交付无收据、担保人写成"见证人"……）
- 没有借条怎么补救：转账记录 + 聊天记录 + 录音 + 还款记录 + 对账确认书

### ✅ 决策：值不值得告、去哪告、要什么材料

- 诉前评估打分卡：金额、证据强度、对方偿付能力、时间成本、执行不能风险
- 诉讼时效自查与中断证据补强
- 催收阶梯：微信/短信 → 电话录音 → 催款函/律师函 → 调解/司法确认
- 管辖：被告住所地 / 合同履行地 / 接受货币一方所在地（可争取原告所在地起诉）/ 协议管辖
- 立案材料逐项清单 + 人民法院在线服务网上立案步骤
- 诉讼费、保全费、执行费分段计算与 5 个金额算例

### ✅ 行动：从起诉状到强制执行

7 类可直接填用的文书模板：

| 文书 | 用途 |
|---|---|
| 规范借条 / 对账确认书 | 事前预防、事后补签、时效中断 |
| 民事起诉状 | 立案（含 2 个完整示例） |
| 证据清单 | 立案与开庭举证、质证意见 |
| 律师函 / 催款函 | 诉前催收、时效中断 |
| 支付令申请书 | 督促程序，快且便宜 |
| 财产保全申请书 | 防止转移财产 |
| 强制执行申请书 | 判决生效后对方不履行 |

### ✅ 过程：法庭上到底发生什么

- 开庭全流程：核对身份 → 法庭调查 → 归纳争议焦点 → 举证质证 → **法庭辩论** → 最后陈述 → 调解 → 宣判
- 举证质证"三性"怎么说；对借条、转账记录、微信记录、录音分别的质证要点
- **法庭辩论提纲**：围绕 5–6 个争议焦点，用「结论 → 事实（对应证据）→ 法律依据 → 回应对方」四段式组织发言
- 对方缺席、当庭提时效抗辩、提反诉、提管辖异议的应对
- 庭审笔录核对、上诉期、申请执行、限高失信、终本与恢复执行

### ✅ 风险：被告常见抗辩与应对

12 类高频抗辩逐条拆解（时效已过、不存在借贷关系、已还款、借条伪造/胁迫、砍头息、高利贷/职业放贷、赌债、夫妻共同债务、保证责任、债务转移/抵销、虚假诉讼、主体不适格），每类给出**抗辩话术 → 法律依据 → 举证责任 → 应对策略**。

## 工作原理

Skill 内置 6 阶段流水线，AI 助手会按阶段收集信息、加载对应参考文件、输出结论：

```
阶段 0  30 秒快速分流   → 证据？时效？财产线索？金额？
阶段 1  事实与证据采集   → 借款金额/交付方式/期限/利息/担保/对方状态
阶段 2  法律分析         → 关系成立？本金？利息上限？时效？无效风险？担保？
阶段 3  路径选择         → 协商 / 律师函 / 支付令 / 小额诉讼 / 普通诉讼 / 保全
阶段 4  文书生成         → 起诉状、证据清单、律师函、保全/执行申请
阶段 5  立案与庭审辅导   → 管辖、材料、网上立案、举证质证、法庭辩论提纲
阶段 6  判决之后         → 上诉、申请执行、限高失信、终本恢复
```

默认输出一份 8 节《借款追偿分析意见》：结论摘要 → 事实梳理 → 证据评估 → 法律分析 → 诉讼请求建议 → 路径建议 → 行动清单 → 风险提示。

参考文件按需加载，不会一次性塞满上下文；法条原文与流程说明都放在 `references/` 下，便于核对与更新。

## 法源与版本

| 法源 | 版本 | 本仓库文件 |
|---|---|---|
| 《中华人民共和国民法典》 | 2020-05-28 通过，2021-01-01 施行 | [借款合同章](./references/legal/民法典-借款合同.md)、[总则与时效](./references/legal/民法典-总则与诉讼时效.md) |
| 《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》 | 法释〔2020〕17 号，2020-12-29 第二次修正，2021-01-01 施行 | [全文](./references/legal/民间借贷司法解释-2020.md) |
| 《中华人民共和国民事诉讼法》 | 2023-09-01 第五次修正，2024-01-01 施行 | [程序条文](./references/legal/民事诉讼法-程序条文.md) |
| 《最高人民法院关于民事诉讼证据的若干规定》 | 法释〔2019〕19 号，2020-05-01 施行 | [证据规则](./references/legal/证据规则与电子数据.md) |
| 《诉讼费用交纳办法》 | 国务院令第 481 号，2007-04-01 施行 | [诉讼费用与时间线](./references/procedure/06-诉讼费用与时间线.md) |

**核心规则一句话版：**

- 自然人之间借款合同**自提供借款时成立**（《民法典》第 679 条）——只有借条、没有转账，要能证明"钱真的给了"。
- 利率上限 = **合同成立时一年期 LPR × 4**（民间借贷司法解释第 25 条）；没约定利息 = 无息。
- 诉讼时效 **3 年**（《民法典》第 188 条），催收要能证明中断。
- 合同纠纷由**被告住所地或合同履行地**法院管辖（《民事诉讼法》第 24 条）；借贷中"接受货币一方所在地"可认定为履行地，很多案件能在**原告所在地**起诉（司法解释第 3 条）。
- 小额诉讼**一审终审**（《民事诉讼法》第 165 条）；支付令被异议即转诉讼（第 225–228 条）。
- 判决生效后 **2 年内**申请执行（第 250 条）。

> 法律会修正。引用前请核对 `references/legal/` 中的原文与文末来源链接；以最新官方文本为准。

## 利息计算器

纯 Python 标准库，无第三方依赖：

```bash
python3 scripts/interest_calculator.py --help

# 借款 10 万，2023-01-01 借出，2023-07-01 到期，年利率 12%，2025-01-01 起诉
python3 scripts/interest_calculator.py \
  --principal 100000 \
  --contract-date 2023-01-01 \
  --due-date 2023-07-01 \
  --annual-rate 0.12 \
  --sue-date 2025-01-01
```

输出借期内利息、逾期利息（按 LPR 分段）、4×LPR 上限校验与可主张合计。计算口径见 [`references/legal/利率与LPR.md`](./references/legal/利率与LPR.md)。

运行测试：

```bash
pip install -r scripts/requirements.txt
python3 -m pytest -q
```

## 使用示例

### 示例 1：只有转账记录，没有借条

> **用户**：2023 年 3 月微信转了 5 万给朋友，他说周转一下，没写借条，现在不还，还说是我还他的钱。能起诉吗？

预期分析路径：
1. 阶段 0：证据 = 转账记录 + 聊天记录；金额 5 万；对方否认。
2. 阶段 2：原告凭转账凭证起诉，被告抗辩"偿还之前债务"的，**被告先举证**（司法解释第 16 条）；被告举证后原告仍要证明借贷合意——用聊天记录、录音补强。
3. 阶段 3：金额 5 万，多数地区可走小额诉讼（一审终审）；若对方身份信息不全，先补被告信息。
4. 阶段 4：生成起诉状（诉请：本金 5 万 + 逾期利息按 LPR）+ 证据清单。
5. 阶段 5：管辖（被告住所地；尝试原告所在地）→ 网上立案 → 开庭提纲（争议焦点：转账性质、借贷合意）。

### 示例 2：写一张能赢的借条

> **用户**：借 20 万给同事，年利率 8%，两年后还，他老婆也要签字，借条怎么写？

预期输出：规范借条全文（含出借人/借款人/配偶信息、金额大小写、转账交付与流水号、年利率 8%、还款期限、逾期利率、实现债权费用、管辖条款、送达地址、保证人/共债确认、签名按印）+ 逐条填写说明 + 提醒核对 8% 是否超过合同成立时 4×LPR。

### 示例 3：第一次开庭，法庭辩论怎么说

> **用户**：下个月开庭，对方说"借条是我被逼写的""钱早还了"，我该怎么辩论？

预期输出：争议焦点归纳（借贷合意是否真实、款项是否交付、是否已还款、时效）→ 举证质证顺序 → 针对每个焦点的辩论提纲（结论 → 事实与证据 → 法律依据 → 回应对方）→ 最后陈述话术 → 庭审笔录核对提醒。

## 可信度分级

本仓库所有法律结论按来源分级标注，避免"道听途说的判例"误导决策：

- ★★★ 法律法规原文、最高人民法院司法解释、指导性案例
- ★★☆ 最高人民法院公报案例、人民法院案例库案例、各省高院裁判指引、官方发布的典型案例
- ★☆☆ 一般媒体报道、律师文章、个人经验总结

`references/类案裁判规则.md` 中每条规则都标注来源与可信度；无法核实的标注「待核实」，**不编造案号与裁判文书**。

## 局限性

- **仅限中国大陆（内地）**。港澳台、涉外借贷的管辖、送达、法律适用规则不同，请咨询律师。
- 不替代律师：涉及大额、抵押担保、公司主体、破产、刑事交叉、虚假诉讼风险的案件，务必委托执业律师。
- 地方法院在立案材料、管辖把握、小额诉讼标准、执行力度上存在差异，具体以当地法院要求为准。
- 裁判结果受证据、法官裁量、对方履行能力影响，本 skill 只做分析与流程辅导，**不承诺结果**。
- 法律与 LPR 会更新；`references/` 中标注了核对日期，使用前请核对最新官方文本。
