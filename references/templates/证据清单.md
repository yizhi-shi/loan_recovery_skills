# 证据清单与质证意见模板

> 适用范围：中国大陆（内地）。本文不构成正式法律意见，重大案件请咨询执业律师。
> 版本核对日期：2026-11（如引用法律有修正，以最新官方文本为准）

**适用场景**：起诉时向法院提交证据目录；开庭前准备质证意见；对方提交证据后进行反驳。

**一句话结论**：民间借贷案件打的就是**"借贷合意 + 款项交付"**两个要件。证据清单不是把材料堆在一起，而是**用表格告诉法官：每一项证据证明哪个要件，缺了哪个要件**。

## 一、证据清单表格模板（标准版）

> **填写说明**
> 1. 用 A4 纸横向打印，或纵向但表格列宽压缩。
> 2. "证明对象"一栏必须写**具体待证事实**，不能写"证明我方主张成立"。
> 3. 页码与装订后的证据册实际页码一致，这是法官核对的关键。
> 4. 份数 = 被告人数 + 1（法院 1 份，每个被告 1 份）。
> 5. **每组证据之间用彩色隔页纸分开**，标注"第一组：借贷合意"等。

## 二、五大证据组：证明目的怎么写

### 第一组：身份信息（证明主体适格）

| 证据 | 证明目的写法 |
|---|---|
| 原告身份证 | "证明原告的姓名、公民身份号码、住址等基本信息，原告系与本案有直接利害关系的公民，具备诉讼主体资格。" |
| 被告身份证/户籍信息 | "证明被告的姓名、公民身份号码、住址等基本信息，被告身份明确、具体，符合《民事诉讼法》第122条第2项'有明确的被告'的起诉条件。" |
| 被告微信/支付宝实名信息 | "证明微信号【XXX】、支付宝账号【XXX】的实名认证人为被告本人，即涉案转账的收款方为被告。" |
| 公司工商登记信息 | "证明被告XX有限公司的主体资格、住所地、法定代表人及统一社会信用代码，该公司系本案适格被告。" |
| 个体工商户登记信息 | "证明被告系个体工商户【字号】，经营者为【姓名】，依《民法典》第56条规定，个体工商户的债务由经营者承担。" |

**写法要点**：身份证据的证明目的就是"**人是对的**"。不要写"证明被告欠钱"，那是后面证据组的事。

### 第二组：借贷合意（证明"借钱"这件事谈成了）

| 证据 | 证明目的写法 |
|---|---|
| 借条 | "证明①原、被告于【日期】就借款事宜达成合意；②借款金额为人民币【】元；③借款期限自【】至【】；④借期内利率为年利率【】%；⑤逾期利率及实现债权费用由被告承担的约定；⑥双方约定由【】法院管辖。该借条由被告亲笔书写并签名按印，系其真实意思表示。" |
| 借款合同 | "证明双方就借款种类、币种、用途、数额、利率、期限、还款方式、违约责任、争议解决等事项作出全面约定（《民法典》第668条），借贷法律关系内容明确。" |
| 微信/短信聊天记录 | "证明①被告于【日期】主动向原告提出借款【】元；②双方就借款金额、利率（月息【】分）、还款期限（【】前还清）通过微信达成一致；③被告于【日期】确认'钱已收到'；④被告多次承认'欠你的钱我会还'。上述内容构成《民法典》第469条规定的以数据电文形式订立的书面合同。" |
| 通话录音 | "证明被告在通话中承认向原告借款【】元、约定利息【】、至今未还的事实；被告的陈述构成对债务的自认。" |
| 证人证言 | "证明【日期】原告在【地点】将现金【】元交付被告，证人全程在场目睹交付过程。" |
| 还款计划书/对账确认书 | "证明被告对欠款金额【】元予以书面确认，并承诺于【】前还清；该确认构成《民法典》第195条第2项'义务人同意履行义务'，诉讼时效中断。" |

**写法要点**：借贷合意的证明目的要落到**"金额 + 期限 + 利率"三个具体数字**上，因为这三项直接决定诉请能否成立。

### 第三组：款项交付（证明"钱真的给了"——最关键）

| 证据 | 证明目的写法 |
|---|---|
| 银行转账凭证/流水 | "证明原告于【日期】通过【银行】账户（尾号【】）向被告账户（尾号【】）转账人民币【】元，转账附言为'借款'，转账流水号【】。依《民法典》第679条及民间借贷解释第9条第2项，自然人之间的借款合同自资金到达借款人账户时成立，本案借贷合同已于该日成立并生效。" |
| 银行柜台业务回单 | "证明上述转账系原告本人到银行柜台办理，回单加盖银行业务专用章，来源合法、内容真实。" |
| 微信转账电子凭证 | "证明原告于【日期】通过微信向被告（微信号【】）转账【】元，转账单号【】。该凭证由财付通支付科技有限公司出具并加盖电子业务专用章，真实可靠。" |
| 支付宝交易流水证明 | "证明原告于【日期】通过支付宝向被告（账号【】）转账【】元，交易号【】。" |
| 收款收据（现金交付） | "证明被告于【日期】当面收到原告交付的现金人民币【】元，收据由被告亲笔签名按印，与借条中'现金交付'的记载相互印证。" |
| 取现记录 | "证明原告于【日期】从本人账户取现【】元，与同日现金交付被告的金额、时间相吻合，佐证现金交付的真实性。" |
| 借款人账户信息截图 | "证明借条中载明的收款账户（尾号【】）确为被告本人开立并实际使用。" |

**写法要点**：这一组是**民间借贷案件的命门**。证明目的必须回答三个问题：**谁转的、转给谁、转了多少**；有转账附言的，一定写进去。

### 第四组：催收与诉讼时效中断（防止"时效已过"抗辩）

| 证据 | 证明目的写法 |
|---|---|
| 微信催收记录 | "证明原告自【日期】起多次向被告催收，被告于【日期】回复'下个月还'，构成《民法典》第195条第2项'义务人同意履行义务'，诉讼时效自该日中断并重新计算。" |
| 短信催收记录 | "证明原告于【日期】向被告手机号【】发送催款短信，要求其在【】日内还款，构成《民法典》第195条第1项'权利人向义务人提出履行请求'。" |
| 催款函 + EMS 单 + 签收记录 | "证明原告于【日期】通过EMS（单号【】）向被告住所地邮寄《催款函》，被告于【日期】签收；原告已向被告提出履行请求，诉讼时效中断。" |
| 律师函 + 邮寄凭证 | "证明原告委托律师于【日期】向被告发出律师函催告还款，被告签收后仍未履行，进一步证明被告违约及诉讼时效中断。" |
| 通话录音（催收） | "证明原告于【日期】电话催收，被告承认欠款并承诺还款，诉讼时效中断。" |
| 报警记录/出警回执 | "证明原告于【日期】因向被告催讨欠款发生纠纷报警，公安机关出警处理，佐证原告持续主张权利。" |

**写法要点**：时效抗辩是被告最常用的"杀手锏"。这一组证据的证明目的要**精确到日期**，并且明确引用《民法典》第 195 条的具体项。

### 第五组：担保与夫妻共同债务（扩大责任财产范围）

| 证据 | 证明目的写法 |
|---|---|
| 借条中的保证人条款 | "证明保证人【姓名】在借条'保证人'处签名按印，明确载明'自愿为上述借款提供连带责任保证'，保证范围包括本金、利息、违约金及实现债权费用，保证期间为借款期限届满之日起三年。依《民法典》第686条、第688条，保证人应承担连带保证责任。" |
| 保证合同 | "证明原告与保证人签订独立保证合同，约定连带责任保证及保证范围、期间。" |
| 保证人身份证 | "证明保证人的身份信息及其诉讼主体资格。" |
| 借款人结婚证/婚姻登记信息 | "证明借款发生在被告【姓名】与【配偶姓名】婚姻关系存续期间。" |
| 配偶签字页 | "证明借款人配偶【姓名】在借条'夫妻共同债务确认'处签名按印，确认知悉并同意该笔借款用于夫妻共同生活/共同经营，构成《民法典》第1064条规定的'共债共签'。" |
| 借款用途证据（装修合同、进货单、转账给配偶的记录） | "证明借款实际用于夫妻共同生活（房屋装修）或共同生产经营（店铺进货），依《民法典》第1064条第2款，应认定为夫妻共同债务。" |

**写法要点**：担保组的核心是"**签名位置 + 身份表述**"。民间借贷解释第 20 条规定，签名未表明保证人身份的，不承担保证责任。所以要重点说明签名处写的是"保证人"而非"见证人"。

## 三、证据目录编排与装订规范

### （一）编排顺序

按**要件顺序**而非时间顺序编排，这是法官阅卷的逻辑：

```
封面（案由、原被告、证据册编号）
  ↓
证据清单（1–2页，表格形式）
  ↓
第一组：身份信息      → 证明"人是对的"
  ↓
第二组：借贷合意      → 证明"借钱谈成了"
  ↓
第三组：款项交付      → 证明"钱真的给了"
  ↓
第四组：催收与时效    → 证明"没过期、催过了"
  ↓
第五组：担保/夫妻债务 → 证明"还有人可以找"
  ↓
附件：计算表、送达地址确认书等
```

### （二）装订规范

| 项目 | 要求 |
|---|---|
| 纸张 | A4（210×297mm），单面打印；原件小于 A4 的，粘贴在 A4 白纸上（四角粘贴，不要用订书钉直接钉原件） |
| 页码 | **右下角连续编号**，从证据清单后的第一页开始编"1"，与清单"页码"栏一致；用打码机或手写均可，但要清晰 |
| 隔页 | 每组证据前加一张彩色隔页纸，标注"第一组 身份信息"等 |
| 装订 | 左侧装订，用订书机或胶装；**不要用夹子**（易散落）；厚度超过 2cm 的分册 |
| 份数 | 法院 1 份 + 每个被告 1 份；自己留 1 份开庭用（**标注"开庭用"并贴标签**） |
| 原件 | **单独装一个文件夹**，开庭时携带，当庭出示核对；不要装订进证据册（装订会损坏原件） |
| 电子证据 | 截图彩色打印；录音刻录光盘（标注文件名、时长、录制时间）+ 文字整理稿；视频存 U 盘 |
| 标注 | 关键内容用**荧光笔标注**或在页面边缘贴标签（如"转账附言：借款"），方便法官快速定位；但**不要涂改、不要遮挡内容** |

### （三）份数与提交节点

| 节点 | 提交内容 | 份数 |
|---|---|---|
| 立案时 | 证据清单 + 证据复印件 | 被告人数 + 1 |
| 举证期限内 | 补充证据 + 补充清单 | 同上 |
| 开庭时 | 证据原件（核对用）+ 开庭用证据册 | 1 套自用 |
| 庭审后 | 按法庭要求补充 | 按通知 |

> **重要**：**举证期限**由法院指定（简易程序一般 15 日，普通程序一般 30 日）。逾期提交的证据，法院可能不予采纳或予以训诫、罚款（《民事诉讼法》第 68 条）。收到举证通知书后，务必在期限内提交完毕。

## 四、质证意见模板

> **质证**是庭审的核心环节：对方出示证据，你从**真实性、合法性、关联性**三方面发表意见。以下按证据类型给出"标准打法"。

### （一）质证的基本框架

对任何一份证据，都按"三性 + 证明目的"四步质证：

1. **真实性**：这份证据是不是真的？形成过程是否可靠？
2. **合法性**：取得方式是否合法？形式是否合法？
3. **关联性**：与本案争议有无关系？
4. **证明目的**：即使真实、合法、有关联，它能不能证明对方想证明的事？

结论只有三种：**认可** / **不认可（说明理由）** / **对真实性认可但对证明目的有异议**。

### （二）对"借条"的质证要点

**如果对方拿出借条向你主张权利（你是被告）**：

```
质 证 意 见

对被告提交的《借条》，发表如下质证意见：

一、对真实性的异议
1. 该借条落款处"【姓名】"的签名并非本人所签，申请进行笔迹鉴定。
2. 该借条系在空白纸上先签名后填写内容，签名与正文的墨迹、书写工具、
   形成时间明显不一致，申请对书写时间进行鉴定。
3. 该借条载明的金额"【】"有明显涂改痕迹，且涂改处无双方签字确认，
   依《民事诉讼证据规定》第90条，存有疑点的书证不能单独作为认定案件
   事实的根据。

二、对合法性的异议
该借条系原告在【时间】【地点】以【威胁/胁迫/限制人身自由】方式逼迫
本人签署，本人已于【日期】向【公安机关】报案（附报警回执），依《民法典》
第150条，一方或者第三人以胁迫手段，使对方在违背真实意思的情况下实施的
民事法律行为，受胁迫方有权请求人民法院或者仲裁机构予以撤销。

三、对关联性及证明目的的异议
即使该借条真实，也只能证明双方有借款的合意，不能证明原告已实际交付
借款。依《民法典》第679条，自然人之间的借款合同自贷款人提供借款时成立；
依民间借贷解释第15条第2款，被告抗辩借贷行为尚未实际发生并能作出合理
说明的，人民法院应当结合借贷金额、款项交付、当事人的经济能力、当地或者
当事人之间的交易方式、交易习惯、当事人财产变动情况以及证人证言等事实和
因素，综合判断查证借贷事实是否发生。原告未提供任何转账凭证、取现记录或
收款收据，其主张的【】元大额现金交付不符合常理。

综上，对该借条的真实性、合法性均不予认可，对证明目的亦不予认可。
```

**如果对方质疑你的借条（你是原告）**，准备以下反驳：

```
反 驳 意 见

针对被告对原告提交的《借条》真实性的质疑，原告说明如下：

1. 该借条由被告本人亲笔书写全文并签名、按指印，书写过程有【录像/
   见证人】为证，被告主张非本人所签，应承担举证责任并申请笔迹鉴定；
   若被告拒不配合鉴定，依《民事诉讼证据规定》第95条，应承担不利后果。

2. 被告主张受胁迫签署，但未提供任何报警记录、伤情鉴定、证人证言等
   证据，其主张不能成立。

3. 借条所载借款金额与原告提交的银行转账凭证（流水号【】）完全一致，
   金额、时间、账户均能对应，足以证明借贷事实真实发生。
```

> **法律依据**：《民法典》第 150 条（胁迫可撤销）；《民事诉讼证据规定》第 90 条（存疑书证不能单独定案）、第 95 条（拒不配合鉴定的不利后果）。★★★

### （三）对"转账记录"的质证要点

**对方拿转账记录主张你欠他钱（你是被告）**：

```
质 证 意 见

对原告提交的转账记录，发表如下质证意见：

一、对真实性无异议
认可该转账记录的真实性，原告确于【日期】向本人转账【】元。

二、对关联性及证明目的有重大异议
1. 该笔转账系【偿还本人此前向原告的出借款/支付的货款/原告归还本人的
   欠款/双方合作项目的往来款】，并非原告向本人出借的款项。
   依民间借贷解释第16条，原告仅依据金融机构的转账凭证提起民间借贷诉讼，
   被告抗辩转账系偿还双方之前借款或者其他债务的，被告应当对其主张提供
   证据证明。本人提交如下证据证明该主张：【证据1】【证据2】。

2. 转账凭证本身只能证明资金流转事实，不能证明资金流转的原因。原告主张
   该笔款项系借款，应就双方存在借贷合意承担举证责任。原告未提供任何
   借条、借款合同、聊天记录或录音证明双方就"借款"达成合意，其主张不能
   成立。

三、结论
对真实性认可，对关联性和证明目的均不予认可。
```

**你是原告，对方抗辩"这是还款/货款"**：

```
反 驳 意 见

被告抗辩涉案转账系"偿还此前借款"，但未提供任何证据证明双方此前存在
借贷关系，其抗辩缺乏事实依据。

依民间借贷解释第16条，被告提供相应证据证明其主张后，原告仍应就借贷
关系的成立承担举证责任。本案中：①原告已提交《借条》证明双方存在借贷
合意；②原告提交的微信聊天记录显示，被告在收款后明确回复"钱收到了，
谢谢"；③被告在【日期】的微信中承认"欠你的钱我会还"。上述证据相互
印证，足以证明涉案转账系原告向被告出借的款项。
```

### （四）对"微信聊天记录"的质证要点

**质疑对方的微信记录**：

```
质 证 意 见

对原告提交的微信聊天记录，发表如下质证意见：

一、对真实性的异议
1. 原告仅提交截图打印件，未提供原始载体（手机），无法核对聊天记录的
   完整性。依《民事诉讼证据规定》第15条第2款，当事人以电子数据作为
   证据的，应当提供原件。电子数据的制作者制作的与原件一致的副本，或者
   直接来源于电子数据的打印件或其他可以显示、识别的输出介质，视为电子
   数据的原件。原告未说明该打印件的制作过程，亦未提供原始载体供核对，
   其真实性无法确认。

2. 该聊天记录存在删减、拼接的可能，未显示完整的对话上下文，且未显示
   对方的微信号、实名信息，无法确认对话对方即为本人。

二、对关联性的异议
该聊天内容系双方关于【其他事项】的交流，与本案借贷争议无关。

三、结论
对真实性、关联性、证明目的均不予认可，请求法院要求原告当庭出示手机
原始记录并演示完整对话。
```

**你的微信记录被质疑，这样回应**：

```
反 驳 意 见

1. 原告已当庭出示手机原始载体，完整演示了与被告（微信号【】、绑定
   手机号【】）的聊天记录，时间、内容与打印件一致，符合《民事诉讼
   证据规定》第15条第2款关于电子数据原件的要求。

2. 该微信号系被告本人实名认证并使用，被告在庭审中已确认该微信号为
   其所有，聊天记录真实性无疑。

3. 聊天记录内容连续完整，能够反映双方协商借款、原告转账、被告确认
   收款、原告催收、被告承认欠款的全过程，与借条、转账凭证相互印证，
   形成完整证据链。
```

> **法律依据**：《民事诉讼证据规定》第 14 条（电子数据范围）、第 15 条（电子数据原件要求）、第 93 条（电子数据真实性审查因素）、第 94 条（可推定真实的情形）。★★★

### （五）对"录音"的质证要点

**质疑对方的录音**：

```
质 证 意 见

对原告提交的录音资料，发表如下质证意见：

一、对合法性的异议
该录音系原告在未经本人同意的情况下秘密录制，且录制地点为本人住所
（私密空间），侵害了本人的隐私权，依《民事诉讼证据规定》第68条，
以严重侵害他人合法权益、违反法律禁止性规定或者严重违背公序良俗的
方法形成或者获取的证据，不得作为认定案件事实的根据。

二、对真实性的异议
1. 原告未提供录音的原始载体（录音设备），仅提交复制件，无法排除
   剪辑、拼接、变造的可能。
2. 录音中对话人的身份无法确认，不能证明系本人声音，申请进行声纹
   鉴定。
3. 录音内容断断续续，关键语句前后不连贯，存在明显的剪辑痕迹。

三、结论
对合法性、真实性、证明目的均不予认可。
```

**你的录音被质疑，这样回应**：

```
反 驳 意 见

1. 关于合法性：该录音系原告与被告之间的正常通话录音，录制于日常
   电话沟通中，未侵害被告的任何合法权益，未采用威胁、欺诈等手段，
   不属于《民事诉讼证据规定》第68条规定的应予排除的情形。司法实践
   中，一方当事人为维护自身合法权益而录制的通话录音，只要不侵害他人
   合法权益、不违反法律禁止性规定，可以作为证据使用。

2. 关于真实性：原告已提交录音原始载体（手机）当庭播放，并提交完整
   的文字整理稿，录音时长【】分钟，内容连续、无剪辑痕迹。

3. 关于身份：录音开头原告明确称呼"【被告全名】"，被告应答，且录音中
   提及的借款金额、时间、转账账户等信息与借条、转账凭证完全吻合，
   足以确认对话对方即为被告本人。
```

> **提示**：录音的合法性边界是"是否严重侵害他人合法权益"。**电话通话录音一般合法**（对方知情或应当知情）；**在他人住宅内偷装设备录音**则可能被排除。录音质量、完整性、身份可识别性，是法官采信的关键。

## 五、证据自查清单（起诉前必做）

### 第一层：要件是否闭合

- [ ] **借贷合意**：有借条/合同/聊天记录/录音中的至少一项，且能确定金额、期限、利率
- [ ] **款项交付**：有转账凭证/收据/取现记录/聊天确认中的至少一项
- [ ] **主体身份**：有被告身份证号，能确定"告的是谁"
- [ ] **未过时效**：有 3 年内的催收记录，或有还款/承诺还款的证据

**四层全部打勾，才建议起诉。缺任何一层，先补证据再起诉。**

### 第二层：真实性与完整性

- [ ] 借条是**原件**（不是复印件、照片）
- [ ] 转账凭证能在银行/微信/支付宝**重新调取**（不是只截了个图）
- [ ] 微信记录保留了**原始载体**（原手机、原账号，未删除）
- [ ] 录音有**原始文件**（不是转发压缩过的）
- [ ] 所有证据的**时间、金额、账户**能相互对应，没有矛盾

### 第三层：形式规范

- [ ] 证据清单已制作，"证明对象"具体
- [ ] 页码连续，与清单一致
- [ ] 份数 = 被告人数 + 1
- [ ] 原件单独存放，开庭携带
- [ ] 电子证据已刻盘/打印，有文字整理稿

### 第四层：反向自查（对方会怎么打）

| 对方可能的抗辩 | 我的应对证据 | 有没有 |
|---|---|---|
| "借条不是我签的" | 签署录像、见证人、笔迹鉴定申请 | ☐ |
| "钱没收到" | 转账凭证、收款确认聊天、收据 | ☐ |
| "已经还了" | （对方举证责任）我方准备反驳其还款证据 | ☐ |
| "这是赠与/投资/货款" | 聊天记录中"借""还""利息"的表述 | ☐ |
| "时效已过" | 催收记录、还款记录、承诺还款记录 | ☐ |
| "利息太高" | 利率未超 4 倍 LPR 的计算说明 | ☐ |
| "是赌债" | 借款用途约定、资金流向、无赌博关联的证明 | ☐ |
| "职业放贷" | 出借人非职业放贷人的说明（借款笔数、非营利性） | ☐ |

## 六、常见错误清单

| # | 错误 | 后果 | 正确做法 |
|---|---|---|---|
| 1 | **"证明对象"写空话**：写"证明我方主张成立""证明被告欠钱" | 法官不知道这份证据要证明什么，等于没提交 | 写具体待证事实，落到**金额、日期、账户、利率**等细节 |
| 2 | **只交借条复印件，原件没带** | 对方否认真实性，你无法核对，可能不被采信 | 原件单独装袋，开庭必带；立案时交复印件 |
| 3 | **微信记录只截有利片段** | 被质疑断章取义，整组证据可信度下降 | 连续完整截屏，含上下文；保留原始载体 |
| 4 | **转账凭证只有手机截图** | 换手机/删记录后无法再现，且截图无银行盖章 | 到柜台打印流水并加盖业务章；微信/支付宝申请带电子章的"转账电子凭证" |
| 5 | **页码与清单不一致** | 法官核对困难，影响庭审效率，甚至要求重新整理 | 装订后统一在右下角连续编号，再回填清单"页码"栏 |
| 6 | **份数不够**（只交 1 份） | 退回补交或当庭无法向对方送达 | 按"被告人数 + 1"准备；自己另留 1 套开庭用 |
| 7 | **证据与陈述矛盾**（说现金交付，却提交转账记录） | 被认定虚假陈述，整体可信度崩塌 | 提交前做"陈述—证据"对照表，逐句核对 |
| 8 | **逾期提交证据** | 法院可能不予采纳，或予以训诫、罚款（《民事诉讼法》第 68 条） | 收到举证通知书后，在举证期限内交齐 |
| 9 | **录音只交文件，不交文字稿** | 法官无法快速核对，可能不予采纳 | 提交光盘/U 盘 + 文字整理稿（标注时间、时长、对话人） |
| 10 | **把"证据清单"当"证据目录"用**，不写证明对象 | 立不上案或庭审被动 | 清单必须含"序号/名称/来源/证明对象/页码/原件复印件"六列 |
| 11 | **篡改、拼接、PS 截图** | 可能构成伪造证据，面临罚款、拘留（《民事诉讼法》第 114 条） | 一律用原始材料；确需标注的，用荧光笔在纸面标注，不改电子文件 |
| 12 | **只提交对自己有利的部分，隐瞒不利证据** | 对方一旦出示，你方陈述可信度受重创 | 主动披露并作出合理解释，比被动挨打好 |
