# 05 支付令、财产保全与小额诉讼：三条"快车道"

> 一句话结论：**不是所有欠款都要走完整诉讼。** 债权清楚、对方可能认账的，先试**支付令**（几十天、三分之一的诉讼费）；金额小的，走**小额诉讼**（一审终审、2 个月）；对方有财产且可能转移的，**先保全再起诉**。

---

## 0. 三条路径速览

| | 支付令（督促程序） | 小额诉讼 | 普通/简易诉讼 |
|---|---|---|---|
| 法律依据 | 民诉法第 225–228 条 | 民诉法第 165 条 | 民诉法第一审程序 |
| 适用金额 | 无上限（但金额大、对方必异议，不建议） | 各省上年度就业人员年平均工资 50% 以下 | 无限制 |
| 时间 | 最快 1–2 个月 | 2 个月（可延长 1 个月） | 3–6 个月 |
| 费用 | 财产案件受理费的 **1/3** | 减半交纳 | 全额（简易程序减半） |
| 终局性 | 生效后可直接执行 | **一审终审**，不能上诉 | 可上诉 |
| 最大风险 | 对方一提异议就失效 | 一审终审，错了只能再审 | 周期长 |

---

## 1. 支付令（督促程序）：最便宜的要债方式

### 1.1 什么是支付令

法院根据债权人的申请，**不经过开庭审理**，直接向债务人发出书面命令，要求其在 15 日内清偿债务；债务人既不履行又不提出书面异议的，支付令即具有**强制执行力**，可直接申请执行。

> 通俗理解：**"法院替你要账的一封正式催款信"，对方 15 天不理，这封信就变成了执行依据。**

### 1.2 适用条件（三个条件必须全部满足）

**《民事诉讼法》（2023 年修正）第二百二十五条**：

> 债权人请求债务人给付金钱、有价证券，符合下列条件的，可以向有管辖权的基层人民法院申请支付令：
> （一）债权人与债务人没有其他债务纠纷的；
> （二）支付令能够送达债务人的。
> 申请书应当写明请求给付金钱或者有价证券的数量和所根据的事实、证据。

逐条翻译成"人话"：

| 条件 | 你要确认什么 | 不满足的后果 |
|---|---|---|
| 请求给付**金钱**、且**数额确定、已到期** | 借款已到期、金额明确（本金 + 明确利息） | 利息还算不清、借款未到期的，不能申请 |
| 与债务人**没有其他债务纠纷** | 你们之间只有这一笔借贷，没有互相欠款、没有其他生意往来纠纷 | 对方可主张"你还欠我货款"使支付令失效 |
| 支付令**能够送达** | 有明确的地址、能实际送达（不能是下落不明需公告送达） | 送达不到的，法院会驳回申请 |

**额外要求**（实务）：债权债务关系**明确、合法**，有借条 + 转账凭证等书面证据；管辖法院为**债务人住所地的基层人民法院**（《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第 23 条），且**基层法院受理支付令申请不受债权金额的限制**（同解释第 427 条）。

### 1.3 申请材料

| # | 材料 | 说明 |
|---|---|---|
| 1 | **支付令申请书** | 写明请求给付的金额、事实与证据。模板见 `references/templates/支付令申请书.md` |
| 2 | 申请人身份证 | 复印件，原件核对 |
| 3 | 被申请人身份信息 | 姓名、身份证号、住址、电话（**必须能送达**） |
| 4 | 债权证据 | 借条/借款合同、转账凭证、催款记录 |
| 5 | 送达地址确认书 | 你的收件地址 |
| 6 | 申请费 | 按财产案件受理费的 1/3 交纳（《诉讼费用交纳办法》第 14 条第（三）项） |

### 1.4 流程与时间轴

```
第 0 日   提交申请
  ↓
第 5 日内 法院通知是否受理（民诉法第 226 条）
  ↓
受理后 15 日内 法院向债务人发出支付令（民诉法第 227 条）
  ↓
送达后 15 日内 债务人二选一：
   ├─ 清偿债务 → 结案（你拿到钱）
   ├─ 提出书面异议 → 支付令失效，督促程序终结 → 转入诉讼程序（第 228 条）
   └─ 既不履行也不异议 → 支付令生效，具强制执行力
  ↓
支付令生效后 → 可直接申请强制执行（不用再起诉）
```

**关键点**：

- 债务人**只能以"书面异议"方式阻却**支付令，口头异议、电话异议无效；
- 异议**几乎不需要理由**——法院虽要审查异议是否成立，但只要异议指向债权债务关系本身存在争议，通常即被认定成立，法院裁定终结督促程序（这是支付令最大的软肋）；
- 支付令失效后**转入诉讼程序**（民诉法第 228 条第 2 款），不需要重新起诉；你不同意继续诉讼的，应当在收到终结督促程序裁定之日起 **7 日内**向法院提出（民诉法解释第 438 条）；转入诉讼后，已交的申请费可以**列入诉讼请求**（《诉讼费用交纳办法》第 36 条）。

### 1.5 费用

| 项目 | 标准 | 5 万元借款的算例 |
|---|---|---|
| 支付令申请费 | 财产案件受理费的 **1/3**（第 14 条第（三）项） | 受理费 1050 元 → 申请费 **350 元** |
| 异议后转诉讼 | 需另交案件受理费 | 1050 元（简易程序减半 525 元） |
| 费用负担 | 债务人未异议的，申请费由**债务人**负担；因异议致程序终结的，由**申请人**负担（第 36 条） | — |

> **省钱逻辑**：5 万元的案子，支付令 350 元就能拿到执行依据（如果对方不异议），比起诉省 700 元且快 2 个月。但**对方一旦异议，350 元就打水漂**（可列入后续诉请）。

### 1.6 优势与风险

| 优势 | 风险 |
|---|---|
| 快：不用开庭，最快 1 个月内生效 | 对方一提书面异议就失效（**异议门槛极低**） |
| 便宜：受理费的 1/3 | 送达不到就驳回（对方失联的不能申请） |
| 简单：一张申请书 + 证据 | 只适用于"无其他债务纠纷"的清楚债权 |
| 有威慑：法院发出的文书，部分人会直接还 | 对方可能借机转移财产（没有保全措施） |
| 生效后可直接执行 | 金额较大的，对方几乎必然提异议，白花钱 |

### 1.7 什么时候用支付令（判断表）

| 情形 | 是否建议 |
|---|---|
| 金额 1 万–10 万元、有借条 + 转账、对方还在正常生活/经营 | ✅ **强烈建议先试** |
| 对方是做生意/开店的，怕麻烦、怕影响征信 | ✅ 建议（支付令有威慑力） |
| 对方已经失联、地址不明 | ❌ 不能申请（送不到） |
| 你们之间还有其他经济往来（互相欠款、合伙、买卖） | ❌ 对方一句"他还欠我货款"就能让支付令失效 |
| 金额 50 万元以上 | ⚠️ 不建议（对方必然异议，且大额案件需要保全） |
| 对方已经在转移财产 | ❌ 直接起诉 + 保全，不要用支付令 |

### 1.8 常见被驳回原因

| 原因 | 解决 |
|---|---|
| 债权数额不确定（利息没算清） | 申请前算清利息，写明确切金额 + 暂计日期 |
| 借款未到期 | 等到期，或主张**预期违约**（需符合法定条件）并直接起诉 |
| 存在其他债务纠纷 | 先理清；确实存在互相欠款的，不能申请支付令 |
| 无法送达 | 提供准确地址；实在无法送达的，改起诉 |
| 证据不足（无书面凭证） | 补强证据（转账 + 聊天 + 录音）后再申请 |
| 管辖法院错误 | 向**债务人住所地基层法院**申请 |

## 2. 财产保全：先把钱"按住"

### 2.1 两种保全

| | 诉前保全 | 诉中保全 |
|---|---|---|
| 法律依据 | 民诉法第 104 条 | 民诉法第 103 条 |
| 时机 | **起诉前** | 立案后、判决前（含执行前） |
| 前提 | 情况紧急，不立即保全将使权益受到难以弥补的损害 | 可能因对方行为使判决难以执行 |
| 担保 | **应当提供担保**（一般相当于请求保全数额） | 可以责令提供担保，**数额不超过请求保全数额的 30%**（《最高人民法院关于人民法院办理财产保全案件若干问题的规定》第 5 条） |
| 紧箍咒 | 保全后 **30 日内**必须起诉/申请仲裁，否则解除保全（民诉法第 104 条） | 无此限制 |
| 裁定时限 | 情况紧急的 48 小时内裁定 | 情况紧急的 48 小时内裁定 |

### 2.2 担保怎么解决（不用真拿几十万现金）

| 方式 | 成本 | 说明 |
|---|---|---|
| **保险公司保全责任险保函** | 保费约为保全金额的 **0.5%–1%**（以保险公司报价为准） | 最常用。向保险公司投保后，由保险公司向法院出具《保全担保书》（《财产保全规定》第 7 条允许保险人以保全责任险提供担保） |
| **现金担保** | 全额占用资金 | 保全 10 万就要交 10 万（诉中可能只交 30%） |
| **房产/车辆担保** | 需评估、办手续 | 要提交权属证明、评估报告，法院审查较慢 |
| **第三人保证** | 免费 | 需保证人有代偿能力，法院可能不接受或要求补充 |

**操作顺序**：先问法院"接受哪种担保 + 指定哪些保险公司" → 找保险公司投保 → 拿到保函 → 连同保全申请书一起提交。

### 2.3 保全申请材料

| # | 材料 | 说明 |
|---|---|---|
| 1 | **财产保全申请书** | 写明保全金额、被保全财产信息、申请理由。模板见 `references/templates/财产保全申请书.md` |
| 2 | 担保材料 | 保函/现金缴款凭证/房产证 + 评估报告 |
| 3 | **被保全财产的具体信息** | 银行账户（开户行 + 账号）、房产（坐落 + 权证号）、车辆（车牌号）、股权（公司名 + 份额）等 |
| 4 | 起诉材料 | 诉中保全提交受理通知书；诉前保全提交拟起诉的材料 |
| 5 | 保全费 | 按实际保全财产数额分段交纳，**最高 5000 元** |

### 2.4 保全费（《诉讼费用交纳办法》第 14 条第（二）项）

| 保全财产数额 | 费率 |
|---|---|
| 不超过 1000 元或不涉及财产数额 | 每件 30 元 |
| 1000 元–10 万元的部分 | 1% |
| 超过 10 万元的部分 | 0.5% |
| **上限** | **不超过 5000 元** |

**算例**：

| 保全金额 | 计算 | 保全费 |
|---|---|---|
| 1 万元 | 30 + （10,000 − 1,000）× 1% = 30 + 90 | **120 元** |
| 10 万元 | 30 + 99,000 × 1% = 30 + 990 | **1,020 元** |
| 50 万元 | 30 + 99,000 × 1% + 400,000 × 0.5% = 30 + 990 + 2,000 | **3,020 元** |
| 100 万元 | 30 + 990 + 900,000 × 0.5% = 30 + 990 + 4,500 = 5,520 → 封顶 | **5,000 元** |
| 500 万元 | 远超上限 | **5,000 元** |

> **保全费由申请人预交**，最终由**败诉方**负担；你胜诉后可在诉请中主张（《诉讼费用交纳办法》第 38 条：保全申请费由申请人负担，申请人提起诉讼的，可以将该申请费列入诉讼请求）。

### 2.5 保全错误的赔偿责任（风险提示）

**《民事诉讼法》**规定：申请有错误的，申请人应当赔偿被申请人因保全所遭受的损失（条文见 `references/legal/民事诉讼法-程序条文.md` 对应条文）。

**什么情况算"保全错误"**：

- 明知没有债权而申请保全；
- 超额保全（申请保全 100 万，实际债权只有 10 万）；
- 最终败诉，且保全缺乏合理依据；
- 保全对象错误（保了案外人的财产）。

**怎么降低风险**：

1. **不要超额保全**：保全金额 ≤ 诉讼请求金额（含利息、费用）；
2. **买保全责任险**：保险公司在保函中承诺"因申请保全错误由保险人赔偿"，这是最有效的风险转移；
3. **保全对象要准确**：只保你确信属于对方的财产，不保配偶/父母名下无依据的财产；
4. **及时起诉**：诉前保全后 30 日内必须起诉。

### 2.6 保全与执行的衔接

- 保全的财产在判决生效后**自动转为执行查封**（你申请执行时说明"已在诉中保全"即可）；
- **查封有期限**：银行存款冻结一般 1 年、动产查封 2 年、不动产查封 3 年（具体以法院裁定和当地规定为准），**到期前要申请续封**，否则自动解封；
- 保全期间对方提供**反担保**的，法院可能解除保全——此时要立即关注其财产动向。

### 2.7 保全操作步骤（清单）

1. [ ] 确认对方有**具体财产**（没有具体线索的，先问法院能否"查控后保全"）
2. [ ] 打电话问受理法院：接受哪种担保？指定哪家保险公司？
3. [ ] 找保险公司投保，拿到《保全担保书》
4. [ ] 写《财产保全申请书》（金额 + 财产信息 + 理由）
5. [ ] 与起诉材料一起提交（诉前保全的，30 日内起诉）
6. [ ] 交保全费，等裁定（紧急的 48 小时内）
7. [ ] 拿到《保全裁定书》→ 核对保全的财产、金额是否正确
8. [ ] 记录查封到期日，提前 1 个月申请续封

**申请书"申请理由"话术模板**：

> "被申请人张XX现正将其名下位于 XX 市 XX 区 XX 小区的房产挂网出售，并频繁转移银行账户资金，存在隐匿、转移财产的现实危险。如不立即采取保全措施，将使申请人的生效判决难以执行。申请人已提供保险公司保全责任险保函作为担保，保全金额未超过诉讼请求金额。依据《中华人民共和国民事诉讼法》第一百零三条，申请对被申请人名下财产采取保全措施。"

## 3. 小额诉讼：金额小的"一次搞定"

### 3.1 适用条件（《民事诉讼法》第 165 条）

> 基层人民法院和它派出的法庭审理事实清楚、权利义务关系明确、争议不大的简单金钱给付民事案件，标的额为各省、自治区、直辖市上年度就业人员年平均工资**百分之五十以下**的，适用小额诉讼的程序审理，**实行一审终审**。
> 基层人民法院和它派出的法庭审理前款规定的民事案件，标的额超过各省、自治区、直辖市上年度就业人员年平均工资百分之五十但在**二倍以下**的，当事人双方也可以约定适用小额诉讼的程序。

**四个条件**：

1. 由**基层法院**（含派出法庭）审理；
2. **简单金钱给付**案件（民间借贷符合）；
3. **事实清楚、权利义务关系明确、争议不大**；
4. 标的额 ≤ 当地上年度就业人员年平均工资的 **50%**。

**标的额怎么查**：

- 各省高院每年会发布本省小额诉讼标的额标准（如 2023 年甘肃为 42,250 元）；
- 打 **12368** 问"今年我省小额诉讼标的额标准是多少"；
- 看受理法院诉讼服务中心的公示。

> ⚠️ **待核实**：各省标准差异较大（多数在 4 万–8 万元区间，经济发达地区更高），且每年随统计口径调整，**以当地高院当年公布的数字为准**。

### 3.2 程序特点

| 特点 | 具体规则 |
|---|---|
| **一审终审** | 判决作出即生效，**不能上诉**；不服只能申请**再审** |
| **审限短** | 立案之日起 **2 个月**内审结，有特殊情况经院长批准可延长 1 个月 |
| **举证期限短** | 一般**不超过 7 日**（双方可约定放弃答辩期和举证期，直接开庭） |
| **送达简化** | 可用电话、短信、电子邮件、传真等方式传唤和送达 |
| **文书简化** | 判决书可以简化，主要记载当事人信息、诉讼请求和裁判主文 |
| **诉讼费减半** | 适用简易程序审理的案件减半交纳案件受理费（《诉讼费用交纳办法》第 16 条） |
| **管辖异议/驳回起诉裁定** | 同样一审终审 |

> **一审终审是双刃剑**：快，但**没有纠错机会**。如果你对事实认定没把握、证据有瑕疵，不要主动选择小额诉讼。

### 3.3 哪些案件不适用小额诉讼

一般包括（以民诉法及司法解释规定为准，具体条文见 `references/legal/民事诉讼法-程序条文.md` 对应条文）：

- 涉及**人身关系**（离婚、抚养、继承）的案件；
- **财产确权**、涉及不动产权属争议的案件；
- **涉外**民事案件；
- 需要**评估、鉴定**或者对诉前评估、鉴定结果有异议的案件；
- 一方当事人**下落不明**（需公告送达）的案件；
- 当事人**提起反诉**的案件；
- 其他不宜适用小额诉讼程序的案件。

> **民间借贷中常见的"不适用"**：被告失联（要公告送达）、被告提反诉（如主张已还款并要求返还多付款）、需要笔迹鉴定的。

### 3.4 小额诉讼 vs 简易程序的区别

| | 小额诉讼 | 简易程序 |
|---|---|---|
| 法律依据 | 民诉法第 165 条 | 民诉法第十三章 |
| 标的额 | ≤ 当地年均工资 50% | 无限制 |
| 审级 | **一审终审** | 可上诉 |
| 审限 | 2 个月（可延长 1 个月） | 3 个月（可延长 1 个月，民诉法第 164 条） |
| 举证期限 | 一般不超过 7 日 | 不超过 15 日 |
| 审判组织 | 审判员一人独任 | 审判员一人独任 |
| 诉讼费 | 减半 | 减半 |
| 程序转换 | 不宜适用的，转为简易程序或普通程序 | 不宜适用的，转为普通程序 |

### 3.5 程序转换（简易 ⇄ 普通）

- **简易 → 普通**：法院发现案件不宜适用简易程序的，在审限届满前裁定转为普通程序，并书面通知双方；**审限自立案之日重新计算**（不是从头再来，是从立案日算总账）；
- **普通 → 简易**：一般不会主动转，除非案件事实清楚且双方同意；
- **小额 → 简易/普通**：发现不符合小额诉讼条件的，转为简易或普通程序；
- 程序转换**不影响你的实体权利**，只是周期变长。

## 4. 三条路径怎么选（决策表 + 决策树）

### 4.1 对比表

| 维度 | 支付令 | 小额诉讼 | 简易程序 | 普通程序 |
|---|---|---|---|---|
| 适用金额 | 无限制（建议 ≤ 10 万） | ≤ 当地年均工资 50% | 无限制（简单案件） | 无限制 |
| 立案到结案 | 1–2 个月 | 2 个月（+1 个月） | 3 个月（+1 个月） | 6 个月（可延长） |
| 开庭 | **不开庭** | 开庭（简化） | 开庭 | 开庭 |
| 上诉 | 不适用（异议即失效） | **不能上诉** | 可上诉 | 可上诉 |
| 费用 | 受理费的 1/3 | 减半 | 减半 | 全额 |
| 保全 | ❌ 无 | ✅ 可申请 | ✅ 可申请 | ✅ 可申请 |
| 适合谁 | 债权清楚、对方会认账 | 小额、证据硬、对方不会赖 | 中等金额、有争议 | 复杂、金额大、有反诉风险 |

### 4.2 决策树

```
对方是否失联 / 地址不明？
 ├─ 是 → 不能支付令（送不到）→ 起诉（可能要公告送达）
 └─ 否 ↓
你们之间是否还有其他债务纠纷（互相欠款、合伙、买卖）？
 ├─ 是 → 不能支付令 → 起诉
 └─ 否 ↓
对方是否已经在转移财产 / 有房产车辆等明确财产？
 ├─ 是 → 起诉 + 财产保全（不要用支付令，来不及）
 └─ 否 ↓
金额是否 ≤ 当地年均工资 50%？
 ├─ 是 → 小额诉讼（一审终审、2 个月、减半）或 支付令（更便宜）
 │        · 对方大概率会认账/怕麻烦 → 支付令
 │        · 对方可能耍赖 → 小额诉讼（有判决，能强制执行）
 └─ 否 ↓
金额是否 ≤ 10 万元且债权非常清楚？
 ├─ 是 → 先试支付令（350 元左右），失效再转诉讼（费用可列入诉请）
 └─ 否 → 起诉（简易或普通程序）+ 视情况保全
```

### 4.3 组合策略（实务最优解）

1. **支付令 → 起诉**：先花 1/3 的费用试支付令；对方异议的，立即起诉，把已交申请费列入诉讼请求。**代价是浪费 1–2 个月**。
2. **保全 → 起诉 → 调解**：对方有财产的，先保全（按住钱），再起诉；保全后对方往往主动来谈，容易调解结案（诉讼费减半）。
3. **诉前调解 → 司法确认**：双方还有商量余地的，走人民调解 + 司法确认，**零费用、可直接执行**（见 `01-诉前评估与催收.md` 第 3.4 节）。
4. **小额诉讼 → 执行**：金额小、证据硬、对方不会出庭的，走小额诉讼，2 个月拿判决，直接执行。

## 5. 操作清单汇总

**想申请支付令**

- [ ] 确认借款已到期、金额确定、能送达
- [ ] 确认双方无其他债务纠纷
- [ ] 写《支付令申请书》（模板：`references/templates/支付令申请书.md`）
- [ ] 向债务人住所地基层法院提交
- [ ] 交申请费（受理费的 1/3）
- [ ] 等待 5 日受理通知 → 15 日发出支付令 → 15 日异议期
- [ ] 对方不异议 → 申请执行；对方异议 → 立即起诉（申请费列入诉请）

**想申请保全**

- [ ] 拿到对方的**具体财产信息**
- [ ] 问法院接受的担保方式 + 指定保险公司
- [ ] 投保保全责任险，拿保函
- [ ] 写《财产保全申请书》
- [ ] 与起诉材料一并提交（诉前保全的 30 日内起诉）
- [ ] 交保全费（最高 5000 元）
- [ ] 拿裁定 → 记录查封到期日 → 提前续封

**想走小额诉讼**

- [ ] 确认标的额 ≤ 当地标准（打 12368 问）
- [ ] 确认对方不会失联、不会反诉、不需要鉴定
- [ ] 立案时说明"本案事实清楚、争议不大，建议适用小额诉讼程序"
- [ ] 接受**一审终审**（不能上诉）
- [ ] 开庭（可简化）→ 2 个月内判决 → 生效 → 执行
